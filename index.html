Como funciona

Em 4 passos simples

01

Importa o extracto

Faz upload do ficheiro CSV, OFX ou MT940 do teu banco. O sistema lê e estrutura automaticamente.

02

Importa os lançamentos

Carrega os lançamentos do ERP do período — manualmente ou via exportação do PHC CS.

03

Matching automático

O motor compara e associa os movimentos. Revisa as partidas em aberto manualmente se necessário.

04

Gera o relatório

Exporta o documento oficial de conciliação em PDF assinado, pronto para arquivo e auditoria.

🗄️ Referência SQL Rápida
ACTIVAR PLANO BUSINESS
UPDATE cao_users
SET plan = 'business',
    trial_ends_at = NULL
WHERE email = 'cliente@email.com';
EXTENDER TRIAL (+30 DIAS)
UPDATE cao_users
SET trial_ends_at = NOW()
    + INTERVAL '30 days'
WHERE email = 'cliente@email.com';
SUSPENDER ACESSO
UPDATE cao_users
SET plan = 'suspended',
    trial_ends_at = NOW()
WHERE email = 'cliente@email.com';
PROMOVER A ADMIN
UPDATE cao_users
SET role = 'admin',
    plan = 'enterprise'
WHERE email = 'tucho@exemplo.com';

Como funciona

Em 4 passos simples

01

Importa o extracto

Faz upload do ficheiro CSV, OFX ou MT940 do teu banco. O sistema lê e estrutura automaticamente.

02

Importa os lançamentos

Carrega os lançamentos contabilísticos do período — manualmente ou via exportação do PHC CS.

Matching automático

O motor compara e associa os movimentos. Revisa as partidas em aberto manualmente se necessário.

04

Gera o relatório

Exporta o documento oficial de conciliação em PDF assinado, pronto para arquivo e auditoria.

⚙️ Configuração Supabase

Liga o ConciliaçAO ao teu projecto Supabase para que os dados persistam e o auth funcione.

Supabase → Project Settings → API → Project URL
Supabase → Project Settings → API → anon public
🗄️ SQL para criar as tabelas — corre no Supabase SQL Editor: 
CREATE TABLE cao_users (id uuid PRIMARY KEY DEFAULT gen_random_uuid(), user_id uuid REFERENCES auth.users(id), name text, company text, plan text DEFAULT 'trial', role text DEFAULT 'user', trial_ends_at timestamptz DEFAULT now() + interval '30 days', created_at timestamptz DEFAULT now());

CREATE TABLE cao_accounts (id uuid PRIMARY KEY DEFAULT gen_random_uuid(), user_id uuid REFERENCES auth.users(id), name text, bank text, iban text, currency text DEFAULT 'AOA', balance numeric DEFAULT 0, status text DEFAULT 'activa', created_at timestamptz DEFAULT now());

CREATE TABLE cao_movements (id uuid PRIMARY KEY DEFAULT gen_random_uuid(), user_id uuid REFERENCES auth.users(id), account_id uuid REFERENCES cao_accounts(id), date date, description text, reference text, amount numeric, type text, status text DEFAULT 'pendente', motivo text, obs text, created_at timestamptz DEFAULT now());

CREATE TABLE cao_accounting_entries (id uuid PRIMARY KEY DEFAULT gen_random_uuid(), user_id uuid REFERENCES auth.users(id), date date, description text, reference text, amount numeric, type text, status text DEFAULT 'pendente', created_at timestamptz DEFAULT now());

ALTER TABLE cao_users ENABLE ROW LEVEL SECURITY;
ALTER TABLE cao_accounts ENABLE ROW LEVEL SECURITY;
ALTER TABLE cao_movements ENABLE ROW LEVEL SECURITY;
ALTER TABLE cao_accounting_entries ENABLE ROW LEVEL SECURITY;
CREATE POLICY "own data" ON cao_users FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "own data" ON cao_accounts FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "own data" ON cao_movements FOR ALL USING (auth.uid() = user_id);
CREATE POLICY "own data" ON cao_accounting_entries FOR ALL USING (auth.uid() = user_id);
As credenciais ficam guardadas localmente no browser (localStorage). Nunca são enviadas para servidores externos.
